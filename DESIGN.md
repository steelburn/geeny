# Notra design system

## Overview

Two clients talk to the same recorder: `web/index.html` (Web Bluetooth console) and
`app/` (Flutter, Android). This file is the shared anchor — change a token here,
then in `app/lib/theme/tokens.dart` and the `:root` block of `web/index.html`.

**Direction:** a field ledger for a pocket recorder. Paper stock, ink type, one forest
accent, measurements set in a monospaced column. The screen should read like a page
someone keeps, not like a dashboard someone generated.

**Subject material:** dictation and field notes — ruled paper, stamped state marks,
handwritten-sized data in tabular columns.

## Colors

Temperature is warm: every neutral is tinted toward the paper (#F5F3ED is not white).
One accent — forest green `#175C44` — carries all actions and all "live" state.
Nothing else is coloured except meaning: `danger` for failures, `warn` for a radio
in progress. No gradients, no glow, no purple.

## Typography

**Five sizes, two families — nothing else.** `34 / 20 / 15 / 13 / 12`. Components pick a
role; they never invent a size.

| role | size | weight | face |
|---|---|---|---|
| display | 34 | 700 | Spline Sans |
| title | 20 | 600 | Spline Sans |
| body | 15 | 400 | Spline Sans |
| small / section | 13 | 400 / 600 | Spline Sans |
| caption | 12 | 400 | Spline Sans |
| data | 13 | 400 | Spline Sans Mono |
| data small | 12 | 400 | Spline Sans Mono |

Every number, serial, hex dump and timestamp is mono with `tabular-nums`, so columns line
up across rows. Section headers are sentence case — no tracked-out all-caps eyebrows.

## Layout

4 px grid (s1–s7). One 1180 px content rail. The app is two columns above 700 px
(facts and controls left, the frame ledger right) and a single column below it.
Rows beat cards: device facts, session counters and the frame log are all fixed
column grids with shared x-positions.

## Elevation

Two named levels, by distance: `elev1` (a 2 px lift) for a card on the paper, `elev2` for
sheets and dialogs, which sit nearer the reader. Nothing else casts a shadow. Hierarchy
otherwise comes from scale, weight and paper-versus-surface, never from stacked shadows.

## Shapes

Radius 4 (chips, inline blocks) and 8 (buttons, panels). Nothing fully rounded except the
status dot.

## Brand mark

The launcher icon is generated by `scripts/make_icon.py`, not drawn per density: forest
stock `#175C44`, a paper `#F5F3ED` microphone with a ruled stand, and one sage `#E3EDE7`
recording light. The same geometry is emitted as the adaptive-icon vector, the legacy
mipmaps, `app/assets/brand/icon.svg` and `web/favicon.svg`. It uses only the tokens above —
no gradient, no outline, no second accent.

## Touch

48 dp for anything you tap in the main flow; 44 dp for dense controls inside a panel
(chips in a filter row, steppers). Nothing smaller.

## Components

- **Primary button** — forest fill, paper text, 46 px tall. Hover darkens to
  `accent-pressed`, pressed goes darker still, disabled drops to `accent-soft` with
  45 %-opacity label, focus adds a 2 px contrasting ring.
- **Outline button** — `surface` fill, hairline border; hover lightens the fill and
  darkens the border, pressed tints with `accent-soft`.
- **Status pill** — 8 px dot + mono label: grey offline, ochre scanning, forest connected.
- **Status bar** — one line: state, serial or elapsed time, and the recorder's free capacity
  in mono at the right (total in the tooltip). It expands only for transfers and notices.
- **Fact row** — 84 px label column (`body-small`, `ink-soft`), mono value column.
- **Log ledger** — `surface` panel, head row of column titles, hairline row separators,
  each row `dir | frame | time` at fixed widths, timestamps right-aligned.

## Do's & Don'ts

- Do keep the accent for actions and live state only.
- Do set every number in mono with tabular figures.
- Don't add a second accent, a gradient, or a shadow as texture.
- Don't put a card inside a card; separate with paper/surface and ledger rules.
- Don't ship a control without disabled, pressed and focus states.
